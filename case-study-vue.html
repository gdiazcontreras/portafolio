01 / CONTEXTO

El proyecto

Vue Product Showcase es una SPA desarrollada con Vue 3 para explorar y gestionar un catálogo de productos consumido desde una API externa. La aplicación integra componentes reutilizables, navegación entre vistas, gestión de estado global y distintas funcionalidades de interacción con los productos.

Desarrollé este proyecto durante mi formación Front-End y me permitió llevar conceptos trabajados previamente con HTML, CSS y JavaScript hacia una arquitectura basada en componentes y una aplicación de página única (SPA).

02 / DESAFÍO

El desafío

El principal desafío fue integrar distintas funcionalidades dentro de una SPA manteniendo una experiencia de navegación clara y una arquitectura organizada. La aplicación debía consumir productos desde una API externa, permitir su exploración mediante filtros, gestionar favoritos y ofrecer vistas de detalle, considerando además distintos estados de la interfaz durante la carga y obtención de datos.

03 / DECISIONES TÉCNICAS

La solución

Vue 3 y Composition API

Construcción de la interfaz mediante componentes reutilizables y lógica organizada con <script setup>.

Vuex

Gestión centralizada del estado relacionado con productos, filtros y favoritos.

Vue Router

Navegación entre vistas y rutas asociadas al catálogo y detalle de productos.

Axios + API REST

Consumo asíncrono de datos de productos desde DummyJSON.

Vuetify

Construcción de una interfaz responsive y soporte para tema claro y oscuro.

Testing

Uso de Jest y Vue Test Utils para pruebas unitarias, junto con Cypress para pruebas end-to-end.

04 / RESULTADO

Resultado

El resultado fue una aplicación funcional que integra en una misma experiencia distintas capacidades propias de una SPA moderna.

  • Catálogo conectado a una API REST.
  • Filtrado y exploración de productos.
  • Gestión de productos favoritos.
  • Navegación hacia vistas de detalle.
  • Manejo de estados de carga, error y ausencia de resultados.
  • Interfaz responsive.
  • Tema claro y oscuro.
  • Pruebas unitarias y end-to-end.

05 / APRENDIZAJES

Principales aprendizajes

  • Comprender la arquitectura basada en componentes de Vue.
  • Gestionar estado compartido entre distintas partes de una aplicación.
  • Integrar y manejar datos obtenidos desde una API REST.
  • Implementar navegación mediante Vue Router.
  • Diseñar estados de interfaz para carga, errores y resultados vacíos.
  • Incorporar pruebas automatizadas como parte del desarrollo Front-End.
